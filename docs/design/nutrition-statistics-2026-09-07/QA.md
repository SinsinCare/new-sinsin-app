# 영양통계 개편 검증 — 2026-09-07

## 최종 화면

핵심 요약과 실천 제안을 별도 카드로 분리했다. 옅은 페이지 배경, 카드 테두리, 섹션 제목, 행 구분선으로 경계를 만들었다. 영양소 이름과 섭취량은 좌우 축에 맞추고 해석은 바로 아래에 유지한다. 기존 서버 수치와 개인 기준은 다시 계산하지 않는다.

## 확인한 동작

- iPhone 17 Pro / iOS 26.5 Simulator, 로컬 Metro 8085 및 기존 로컬 API를 사용했다.
- 실제 빈 일간 화면과 기록이 있는 일간·주간·월간 화면을 확인했다. 최종 카드 변경은 명시적 Reload 후 다시 확인했다.
- 기간 전환, 이전 기간 이동, 달력 날짜 선택, 주간 차트 날짜 선택 후 일간 이동, 빈 상태의 식사 기록 CTA로 홈 복귀를 확인했다.
- 최종 월간 화면을 라이트·다크 모드 및 글자 크기 두 단계 증가 상태에서 확인했다. 헤더·요약·실천 카드가 겹치거나 잘리지 않았다. 글자 크기와 앱 라이트 모드는 검사 전 값으로 복원했다.
- 별도 임시 화면에서 합성 일간·주간·월간 자료, 전체 해석, 초과 비율이 다른 막대, 누락 기록, 로딩과 오류 화면을 확인했다. 합성 자료는 API 요청·캐시·저장·분석 이벤트와 연결하지 않았다. 임시 화면은 삭제했다.

## 검증 한계

CUA의 scroll/drag 호출이 noWindowsAvailable로 실패했다. 하단 합성 레이아웃은 임시 화면의 scrollTo 버튼으로 확인했으며, 이를 손가락 스크롤·감속·끌림 확인으로 간주하지 않는다. 오류 화면은 확인했지만 재시도 성공 복귀는 확인하지 못했다. 실제 기기와 Android는 이번 검증에 포함하지 않았다. 실제 개인·건강 수치는 이 문서에 보관하지 않는다.

## 코드 검사

- 전체 TypeScript 검사, 변경 경로 ESLint, diff 공백 검사: 통과.
- 표시 회귀 4개와 언어별 쿼리 키 5개: 통과.
- 통계 분석 이벤트 관련 검사 8개: 통과.
- 전체 analyticsJourneyHome 실행에는 기존 혈압 입력 훅의 소스 문자열을 요구하는 관련 없는 테스트 1개가 실패한다. 통계 변경을 위해 해당 테스트나 혈압 구현을 수정하지 않았다.
- 한국어 문구 감사: 종료 코드 0. 기존 다른 영역 후보 14개가 남아 있으며 변경한 통계 문구에는 새 후보가 없다.

## 보존한 정보

결론·근거·기록 충실도, 실천 제안과 보조 설명, 겹친 건강 신호, 유지할 습관, 영양소별 수치·개인 기준·해석·각주, 식사 목록, 주간 칼륨·체중 차트, 월간 주별 비교, 기간 평균, 건강 기록과 해석, 의료진 상담 안내를 유지한다. 데이터가 없다는 이유로 존재하는 건강 경고를 빈 화면으로 대체하지 않는다.

## 후속: AI 해석의 구분과 상담 연결

실제 월간 응답의 AI 출처에 따라 캐릭터와 AI 해석 헤더가 표시되는 것을 Simulator에서 확인했다. 근거 라벨과 실천 제안은 별도로 유지한다. 처음에는 리포트만 첨부한 빈 상담으로 연결했으나 사용자가 상담 홈 이동으로 지적하여 아래 시작 동작으로 수정했다.

추가 컨텍스트 검사 2개와 기존 표시 검사 4개 통과, 전체 TypeScript 통과, 변경 경로 ESLint 오류 없음(테스트 import 서식 경고 교정), 문구 감사의 기존 후보 수 14개 유지. AI 모델·프롬프트·의료 판단 로직은 이 후속 변경의 대상이 아니다.

## 후속: 버튼에서 상담 바로 시작

명시적인 리포트 상담 버튼을 누르면 선택한 기간의 리포트와 첫 질문을 함께 보내도록 변경했다. Simulator에서 사용자 리포트 카드와 답변 생성 상태가 즉시 표시되는 것을 확인했다. 실제 로컬 상담 서비스의 답변이 선택한 월간 리포트의 기록과 기간을 근거로 설명하는 것까지 확인했다. 저장된 해당 대화를 상담 기록에서 다시 열어 첨부 카드와 완료 답변이 유지되는 것도 확인했다. 검증 과정에서 해당 상담 1건이 생성됐으며 임의 삭제하지 않았다. 건강 기록은 변경하지 않았다.

메시지 빌더·파서·리포트 컨텍스트·기존 식사/검진/식당 파서 우선순위 검사 19개 통과. 최종 TypeScript 및 변경 경로 ESLint 통과, 문구 감사의 기존 후보 수 14개 유지. 버전 표식이나 JSON이 채팅 버블에 노출되지 않는다.
