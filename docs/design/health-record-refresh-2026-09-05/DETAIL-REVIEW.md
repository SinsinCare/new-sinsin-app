# 건강 기록 6개 페이지 상세 재점검

2026-09-05. 이전 REVIEW.md의 시각 점검만으로 입력 전후 상태까지 보장할 수 없었으므로 다시 점검했다. iPhone 17 Pro, iOS 26.5, 기존 Metro 8085 테스트 세션에서 확인했다. 서버에 임의 건강 기록을 저장하지 않았다.

## 수정 내용

- 숫자 입력의 iOS 기본 placeholder를 별도 텍스트로 그린다. 실제 입력과 같은 글자 크기 및 시스템 배율을 사용하고, 숫자를 지웠을 때도 프레임 높이를 유지한다. 입력 자체는 네이티브 TextInput을 유지한다.
- 숫자·단위·라벨은 공통 입력 컴포넌트를 사용한다. 큰 글자에서 혈압 두 칸은 세로로 배치하고 체중·혈당의 단위도 아래로 이동한다.
- 오류 안내 두 줄의 공간을 먼저 확보한다. 키보드가 열리면 입력 아래 단위와 안내 문장까지 보이도록 스크롤 여백을 확보하고, 안내 글자에 덮이던 하단 페이드를 끈다. 평상시 페이드도 36pt에서 16pt로 줄였다.
- 실제 하단 버튼 높이를 측정해 스크롤 여백에 반영한다. 큰 글자나 긴 버튼 문구에도 마지막 항목을 가리지 않도록 한다.
- 선택지는 번역 문구 길이, 화면 너비, 글자 배율에 따라 열 수를 조정한다. 마지막 줄의 빈 칸은 유지해 단독 선택지만 넓어지지 않게 한다.
- 수분 직접 입력 시트에서 페이지와 중복되던 빠른 추가 버튼을 제거했다. 삭제 버튼 공간과 오류 안내 공간을 유지해 입력·삭제·오류 전환 때 단위나 버튼 위치가 움직이지 않는다.
- 혈압·체중 입력 상태를 기능 훅으로 분리했다. 혈압은 측정 맥락별 편집을 보존하고, 새 측정의 맥락을 바로잡을 때 입력을 가져간다. 조회 갱신이 편집 중인 값을 덮어쓰지 않는다. 체중은 첫 렌더부터 저장값을 표시한다.
- 여섯 페이지의 라우트 정리는 실제 화면이 제거될 때 수행한다. 뒤로가기를 취소했을 때 입력 화면을 먼저 비우지 않는다.
- 혈당은 공복을 선택했다가 식후로 돌아와도 이전 끼니와 경과 시간을 되살린다. 공복의 저장 데이터에서는 끼니와 경과 시간을 제외한다.
- 현재 API의 허용 범위에 맞춰 혈압·심박수·혈당 입력을 검사한다. 범위 초과 시 저장 버튼을 비활성화하고 이유를 표시한다.
- 다크 모드의 입력 라벨·단위·요약 카드 설명·체중 기록 행은 공통 보조 글자 색으로 대비를 보강했다. 오류 안내에는 작은 글자에도 읽히는 적색 토큰을 사용한다.
- 기록 페이지가 보이는 동안 상태 표시줄에 현재 테마를 적용한다. iOS 키보드 전환 뒤 글자가 검정으로 남는 현상을 재현해, 키보드 표시·숨김 완료 시에도 현재 색을 다시 적용했다. 혈당에서 열기·닫기와 페이지 이동 후 밝은 상태 표시줄을 확인했다.

수분·부기 미저장 확인은 실제 팝업에서 유지와 폐기를 각각 확인했다. 모든 임시 입력은 지우거나 폐기했고 기존 서버 기록은 변경하지 않았다. 입력이 필요한 저장 성공·실패·중복 요청은 실제 훅과 모의 저장 경계를 사용하는 자동 검사로 검증했다.

## 검증 범위와 환경

- 라이트 기본 크기 및 세 단계 큰 글자에서 여섯 페이지를 모두 직접 확인했다. 글자 크기는 세 단계 낮춰 원래 값으로 복원했다.
- 저장 성공 문구·실패 후 초안 보존·연속 탭 잠금·완료 후 기록 갱신은 회귀 검사로 확인한다. 실제 계정에 시험 기록을 저장하는 검사는 하지 않았다.
- 앱 설정의 다크 모드로 전환해 여섯 페이지의 숫자·단위·라벨·선택지·버튼을 직접 확인했다. 혈당 오류 입력도 지웠으며, 점검 뒤 앱 설정을 원래 라이트 모드로 복원했다. 시스템 글자 크기와 외관 설정도 원래 값으로 복원했다.
- 화면 이동, 선택, 키보드 내리기와 보조 시트 종료를 직접 확인했다. 프레임 속도를 계측한 성능 검사나 모든 기기의 검증은 아니다. 애니메이션은 시스템 동작 줄이기 설정을 따르는 기존 공통 설정을 유지한다.
- 이번 확인은 iOS 테스트 런타임 기준이다. Android 기기, 배포 빌드 또는 프로덕션 저장까지 검증했다고 주장하지 않는다.
- `npm run audit:ux-copy`와 `git diff --check`를 실행했다. 문구 감사의 기존 후보 12개는 이번 건강 기록 문구 변경에서 발생한 항목이 아니다.

실행 가능한 검사 결과와 최종 판정은 DETAIL-GATES.md에 기록한다.
