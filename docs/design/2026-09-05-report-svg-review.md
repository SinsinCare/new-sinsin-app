## 차이와 수정

시안은 제목, 본문, 보조 정보의 크기와 굵기가 명확히 나뉜다. 기존 구현은 헤드라인 20, 본문 17, 추천 문구 17/600, 열량 24/700, 집중 영양소의 큰 숫자와 굵은 고리를 동시에 사용했다. 숫자와 카드마다 강조가 겹쳐 시안보다 밀도가 높았다.

시안의 예시 숫자, 음식명, 판정은 실제 사용자 기록에 복사하지 않았다. 영양 수치와 판정 계산은 기존 동작을 유지한다.

## 확인

- iPhone 17 Pro, iOS 26.5, 로컬 API 8100 / Metro 8085에서 `우유 200g` 실제 글 분석으로 확인.
- 글 분석 결과의 사진 없는 구성, 네 고리의 동일 굵기, 짧은 하단 버튼 반영을 화면과 접근성 트리에서 확인.
- 수정 버튼의 좌표 터치로 수정 화면 진입을 확인. 안전 영역 수정 후 제목이 온전히 표시됨.
- 미저장 확인창의 두 버튼이 잘리지 않고 표시됨. 돌아가기 버튼을 누른 뒤 사용자가 시뮬레이터에서 새 분석을 시작해, 결과 보존 동작은 별도 완료 주장에 포함하지 않음.
- UX 문구 감사 실행 완료. 기존 다른 문구의 교정 후보 12개는 이번 변경 대상이 아님.
- 스크롤 영역은 실측 높이 590, 내용 752로 측정됨. 자동화 드래그는 `onTouchStart`만 전달하고 `onTouchMove` 및 `onScrollBeginDrag`는 전달하지 않아 실제 드래그 스크롤은 미확인. 측정용 임시 코드는 제거했다.
