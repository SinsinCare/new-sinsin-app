## 적용

- 탭·화면 이름을 ‘내 정보’로 통일. 헤더 우측은 44pt 높이의 설정 아이콘+라벨. 프로필 수정과 앱 설정을 다른 진입점으로 구분.
- 건강 프로필은 병기·투석 여부·체중의 간결한 요약. 진행률처럼 보이던 병기 그래픽 제거. 나머지 건강 정보는 기존 상세 수정 화면에서 접근. 미입력·로딩·조회 실패를 구분.
- 건강 메뉴가 먼저 보이고 구독은 한 행으로 축소. 무료의 기존 프리미엄 진입과 유료의 관리 경로 유지. 가격이나 건강 수치를 새로 만들지 않음.
- 동일한 목록 행·섹션 컴포넌트를 양쪽에 적용. 기본 메뉴 15/20pt, 보조 정보 13/18pt, 좌우 20pt, 단일 행 최소 52pt. 글자가 길면 높이가 늘어날 수 있으며 한 줄 강제 잘림을 피함.
- 설정은 계정 / 앱 환경 / 알림 / 약관 및 앱 정보 / 계정 관리 순서. 화면 모드·언어는 요약값을 누르면 선택창을 연다. 확인된 선택값만 체크하고, 취소는 값을 바꾸지 않는다.
- 서비스 이용약관과 개인정보 처리방침을 해당 문서로 직접 연결. 앱 정보는 버전과 함께 표시.
- 설정 스택의 루트 화면을 명시. 내부 전환 완료와 선택창 닫힘 뒤 상태바 색을 앱 테마에 맞춤.
- 알림 조회 실패 시 재시도 제공. 초기 조회 전·저장 중 쓰기 잠금. 저장 실패 시 이전 값 유지. 저장 전에 시작한 느린 조회는 최신 저장값을 덮지 않음. 언어 저장 실패 시 선택창 유지, 뒤늦은 완료가 새로 연 다른 선택창을 닫지 않도록 보호.
- 건강 기록 내보내기 본문 생성 로직은 그대로 별도 훅으로 이동. 공유는 해당 버튼을 사용자가 눌렀을 때만 실행.

## 검증
