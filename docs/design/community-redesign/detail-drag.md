# `detail-drag` — 자유글 게시물 상세 (스크롤 하단부)

캔버스 영역: x 100–1810, y 7190–8220.
섹션 헤더 원문: **"자유글- 인기글, 최신 게시글 / 게시물을 클릭했을때 드레그"**

모든 수치는 **@1x px**, SVG 좌표에서 실측했다. 프레임 로컬 좌표 = 절대좌표 − 프레임 원점.
텍스트는 아웃라인 패스라 **잉크(ink) 박스**를 잰 값이다. 폰트 크기는 잉크 높이로 역산했다
(Pretendard 실측 비율: **한글 잉크 = 0.869 × fontSize**, **숫자 cap = 0.715 × fontSize**,
**한글 advance ≈ 0.855 × fontSize**). 본문 3줄의 baseline 피치가 정확히 **20px**이고 한글 잉크가
11.3 → fontSize 13 → `typography.body.xSmall (13/20)` 과 정확히 일치하므로 이 보정은 신뢰할 수 있다.

## 1. 화면 인벤토리

네 프레임 모두 **같은 화면(게시물 상세 = `app/post/[id].tsx`)의 서로 다른 스크롤 위치**다.
상태 머신이 아니라 **하나의 긴 스크롤을 4컷으로 자른 것**이다(섹션 제목의 "드레그"가 그 뜻).
헤더(앱바)는 **불투명 흰 바가 콘텐츠 위에 고정**되어 있고 콘텐츠가 그 아래로 지나간다

- F1·F2는 같은 댓글 리스트를 위/아래로 나눠 보여준다. 대댓글(들여쓰기+회색 배경) 행은 F1에서 2번째, F2에서 2번째(같은 행)다.

이 구간에는 **명시적 상태 프레임이 없다**(4컷 모두 같은 상태의 다른 스크롤). 시안이 함의하는 동작:

| `마지막 댓글로` | 댓글 리스트 맨 끝으로 점프(스크롤 액션). 텍스트 버튼 |

**시안에 없는 상태(구현이 알아서 정해야 함)**: 빈 댓글, 댓글 로딩(스켈레톤), 오류, pressed, disabled,
키보드 올라온 레이아웃, 팔로우 진행중(pending), 삭제된 댓글, 탈퇴 작성자.
→ v2 규칙대로 **링 스피너 금지, 스켈레톤 우선**(`V2Skeleton`), 빈/오류는 `V2EmptyState`/`V2ErrorState`.

**시안 내부의 불일치(수정 제안)**
1. 밴드 위/아래 여백이 8 / 8 / 16으로 섞여 있다 → **밴드 위 16, 아래 8**로 통일 권장(`더보기` 필 뒤엔 이미 16).
2. `이런 작성자도 만나보세요` 섹션만 밴드→헤더 간격이 16이다 → 8로 통일.
3. peek 카드(3번째)의 버튼 y가 3px 낮다 → 무시.
4. `최신순`(13) vs `마지막 댓글로`(12) — 같은 줄에서 1px 차이. 12로 낮추거나 13으로 올려 하나로.

### v2에 없어서 추가가 필요한 것 (최소 추가안)

1. **8px 섹션 밴드** — `V2Divider variant="thick"` 는 16 고정. → `thickness?: 8 | 16` 프롭 하나 추가(기본 16).
2. **kebab(더보기) 아이콘** — `icons/registry.ts` 에 `more`(ellipsis-horizontal) 추가. 지금은 Ionicons를 쓰고 있어 v2 아이콘 계보 밖이다.
3. **솔리드 하트 / 솔리드 말풍선** — `heartFilled`, `chatFilled` 추가(또는 `heart`가 이미 솔리드인지 확인).
4. **14px 아이콘 사이즈** — `iconSize`는 16이 최소. 메타 행 아이콘 잉크가 12.3×11.1 → 프레임 14. → 16으로 올리고 gap을 4→3으로 줄이면 시각적으로 거의 같다. **토큰 추가보다 16 사용을 권장**.
5. **pill radius 버튼** — `V2Button` size별 radius가 고정(`sm/md/xl/2xl`). `더보기` 필은 full. → `V2Button` 에 `pill?: boolean` 추가(가장 작은 추가) 또는 `style` 로 덮기.
6. **높이 21–22의 마이크로 칩** — `V2Chip`(32) / `V2Badge`(패딩 기반) 어느 쪽도 21 고정이 아니다. `V2Badge size="xs"` 가 10px 텍스트 + py2 = 약 20 로 가장 근접하니 이걸 쓰고 `borderRadius: radius.full` 만 덮는다.
7. **10px Medium 타이포** — `caption.xSmall` 는 10 **SemiBold**. 카드 배지 칩은 Regular/Medium으로 보인다. 굵기 차이를 감수하거나 `caption.xSmallWeak`(10 Medium) 추가.
8. **12px Medium** — 이전/다음 칩. `caption.small`(11 Medium)과 `subtext.small`(12 Regular) 사이. → `subtext.small` 로 스냅 권장(굵기 손실 감수).
9. **15/19 Medium** — 목록 행 제목. `label.smallWeak`(15/19 Medium)로 **정확히 존재** ✅.

### v2 규칙과 충돌하는 지점

| 충돌 | 처리 |
|---|---|
| 화면 좌우 거터 시안 **20** vs `layout.GUTTER = 16` | 이 화면은 20이 일관되게 쓰였다. **`GUTTER`를 바꾸지 말고** 커뮤니티 상세 로컬 상수(`POST_GUTTER = 20`)로 두고, 전사 통일은 별건으로. 프로필 카드 아바타만 24라 **20으로 내려 시작선을 하나로** 만들 것을 권장. |
| back chevron `#2E2F33 @88%` | 토큰에 없다. `colors.label.normal`(#2a2a37) 또는 `label.neutral`(70%)로 스냅. **normal 권장**(back은 강조 요소). |
| 아이콘 실효 알파 30.6% | `label.assistive`(27.8%)로 스냅. 육안 차이 없음. |
| `fill.pressed` 를 아바타 배경으로 사용 | 값은 같지만 이름이 오해를 부른다. 아바타 플레이스홀더 전용 별칭(`avatarPlaceholder`)을 surface 레이어에 두는 편이 낫다. |
| 시안엔 letterSpacing 0 | v2 규칙과 일치. **현재 구현의 −0.2~−0.4 를 전부 제거해야 한다.** |
| 굵기를 `fontWeight` 로 주면 안 됨 | 모든 Bold/Medium은 `typography.*` 토큰(=face)으로만. `AppText`/`V2Text` 사용. |

### 10.3 **시안에 없지만 반드시 보존해야 하는 현재 기능** (지우지 말 것)

시안은 스크롤 하단부만 보여준다. 아래는 전부 현재 구현에 있고 **시안이 침묵할 뿐 없애라는 뜻이 아니다.**

1. **하단 댓글 입력 바** — `KeyboardStickyView` + `TextInput`(multiline, maxLength 2000) + 전송 버튼(36×36). 시안 4컷 어디에도 없지만 **댓글을 달 수단이 사라지면 안 된다.**
2. **멘션 전체** — `MentionSuggestions` 플로팅 패널, 확정 멘션 칩(`@닉네임` + 닫기), `applyMention`/`findMentionQuery`/`removeMention`/`retainedMentions`, `MentionText` 렌더.
3. **답글/수정 컨텍스트 바** — `replyingTo` / `editingCommentId` 일 때 입력 바 위에 뜨는 `…님에게 답글`/`댓글 수정 중` + 취소 버튼.
4. **공유(share)** — 앱바 share 아이콘 + `shareContent` + `communityPostDeepLink` + `STORE_REDIRECT_URL`. 시안 앱바엔 아이콘이 없으니 **kebab 메뉴로 옮기되 기능은 유지**.
5. **북마크(bookmark)** — 같은 이유로 kebab 또는 메타 행으로 이동. `togglePostBookmark` 유지.
6. **신고·차단·수정·삭제** — 게시물 kebab(`handleMorePress`)과 댓글 kebab(`handleCommentMore`), `reportComment`, `useBlockedUsers`, `isMyContent` 기반 내 글/남의 글 분기. **소유자 판정은 서버 `isMine`** 규칙 그대로.
7. **투표 카드(`PollCard`)** + `castVoteAsync` / `isVoting`.
8. **태그(`TagChips`)** + `onPressTag` → 태그 검색 이동.
9. **이미지**: 1장이면 4:3 큰 이미지, 여러 장이면 가로 스트립(200×200, r14), 탭하면 `AppModal` 전체 보기 + 닫기.
10. **당겨서 새로고침** — `useRefreshable(COMMUNITY_POST_REFRESH)` + `useRevalidateOnReturn`.
11. **상태 화면** — `ArticleSkeleton variant="post"`(로딩), `ErrorMessage` + `resolveError().retryable` 분기(지워진 글은 재시도 버튼 없음), 글 없음 화면. **이 분기는 회귀시키지 말 것.**
12. **탈퇴 작성자 처리** — `isWithdrawnAuthor` / `WITHDRAWN_AUTHOR_NAME`: 이름 대체, 프로필 이동 비활성, kebab 숨김.
13. **삭제된 댓글** — `comment.isDeleted` 일 때 문구 대체 + 액션 숨김.
14. **좋아요 하트 스프링 애니메이션**(`HEART_SPRING`, `ReduceMotion.System`) 및 `hapticSelection`.
15. **댓글 로딩/오류/빈 상태 3분기** — 시안엔 없다. 유지하되 v2 `V2Skeleton`/`V2EmptyState`/`V2ErrorState` 로 갈아끼울 것(링 스피너 금지).
16. **i18n** — 모든 문구가 `t(...)` 키다. 시안의 한국어 문구는 **ko 값으로만** 넣고 하드코딩하지 말 것. 새로 필요한 키: `최신순`, `마지막 댓글로`, `작성자`, `답글쓰기`, `댓글 더보기`, `이전`, `다음`, `후기`, `팔로워`, `팔로잉`, `팔로우`, `{name}의 다른글`, `게시글 더보기`, `추천 게시글`, `인기글 더보기`, `이런 작성자도 만나보세요`, `조회 {count}`.

### 10.4 데이터 갭 (구현 전에 결정 필요)

| 시안이 요구하는 것 | 현재 있는 것 | 판단 |
|---|---|---|
| 스탯 1번 라벨 **`후기`** (30) | `CommunityAuthorProfile.postCount` (라벨 `게시글`) | 시안 라벨이 "후기"인데 API는 글 수다. **라벨을 `게시글`로 두거나, 후기 수 필드를 서버에 요구**. 값을 지어내면 안 된다. |
| 댓글 정렬(`최신순`) | 정렬 옵션 없음 | 서버 지원 확인 필요. 없으면 클라 정렬 or 이 컨트롤 보류 |
| `마지막 댓글로` 점프 | 없음 | 스크롤 액션이라 클라만으로 가능 |
| 이전/다음 글 | 없음 (`useCommunityPosts` 목록에서 인접 글 계산은 가능) | 목록 캐시로 유도 가능. 캐시가 없으면 섹션 자체를 숨길 것(조용한 폴백 금지) |
| `{작성자}의 다른글` | `communityPostService` 에 작성자별 글 목록 존재(작성자 프로필 화면이 씀) | 재사용 가능 |
| 이미지 개수 배지 | `post.imageUris.length` 있음 | 가능 |
| `이런 작성자도 만나보세요` | **추천 작성자 API 없음** | 서버 필요. 없으면 섹션 미표시 |
| 댓글 좋아요 수 0일 때 | 현재 `likes > 0` 일 때만 숫자 표시 | 시안은 **0도 표시**(대댓글 `0`) → 항상 표시로 변경 |
