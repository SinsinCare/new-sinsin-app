# `feed-drag` — 자유글 피드 (스크롤/드래그 상태)

캔버스 섹션 라벨: **"자유글- 자유글 드레그"** (검은 띠, x≈141–1450, y≈290–390).
영역: x 100–1010 / y 460–1840. 이 영역에 실제로 들어있는 폰 프레임은 **2개뿐**이다
(x=955 자리에는 프레임이 없다 — 다음 섹션은 x=1362 부터 시작).

모든 수치는 **@1x px**, SVG 소스에서 실측한 값이다(경로 bbox를 베지어 샘플링으로 계산).
글자 크기는 Pretendard 실제 metrics(upem 2048, 한글 advance 0.864em, cap 0.707em,
space 0.251em, `.` 0.254em)로 **글리프 원점 간 거리 ÷ 0.864** 로 역산했다 — 눈대중 아님.
굵기는 세로 스템 폭 ÷ fontSize 로 판정했다(Regular 0.0765 / Medium 0.089 /
SemiBold 0.103 / Bold 0.1167 기준선, Regular·Bold는 실제 otf 렌더로 검증).
검증: 검색 placeholder가 0.0888 → Medium 으로 나왔고 이는 `V2SearchField` 스펙
(`label.mediumWeak` 17 Medium)과 정확히 일치, 상단 탭도 선택=Bold/비선택=SemiBold 로
나와 `V2Tab` size `l` 스펙과 정확히 일치한다.

## 1. 화면 인벤토리

| # | 프레임 원점 (x,y) | 크기 | 화면 | 상태 |
|---|---|---|---|---|
| A | (141, 512) | 375 × **1283** | 커뮤니티 · 자유글 탭 (피드) | **스크롤 최상단**. 고정 헤더(탭+검색) 아래로 `게시글` 섹션 제목 + 정렬 드롭다운이 보이고, 글 4개 → `이런 작성자도 만나보세요` 레일 → 글 1개(하단 잘림) |
| B | (548, 512) | 375 × **1283** | 같은 화면 | **A를 아래로 274px 스크롤한 상태**. `게시글` 제목과 정렬 드롭다운은 이미 위로 빠져나갔고, 첫 글 카드가 고정 헤더 밑으로 반쯤 잘려 들어간다. 그 아래는 A와 같은 리듬이 계속되고 레일 뒤로 글 3개가 더 보인다 |

- **A와 B는 같은 화면의 스크롤 오프셋 차이 하나뿐**이다. A의 `이런 작성자도 만나보세요`
  헤더는 y=1316, B는 y=1042 → **정확히 274px 차이**. A의 2번째 글 행(y=929, 높이 147)이
  B의 y=655 행과 동일 → 274 확인.
- 프레임 높이가 1283 인 것은 실제 기기 높이가 아니라 **스크롤 내용을 길게 펼쳐 보여주기 위한
  연장 프레임**이다. 실기기(375×932 가정)에서 스크롤 뷰포트는 y 173–848(local) = 675px.
- **이 영역에 정렬 드롭다운이 "열린" 오버레이 프레임은 없다.** 두 프레임 모두 정렬 칩은
  닫힌 상태(`최신순 ⌄`)다. 오버레이(최신순/조회순/인기순 목록)는 이 영역 밖
  (x ≥ 1362 프레임들)에 있을 것이므로 해당 섹션 스펙을 참조해야 한다.

이하 좌표는 **프레임 로컬**(프레임 좌상단 = 0,0). 캔버스 좌표로 바꾸려면 A는 (+141, +512),
B는 (+548, +512).

## 5. 상태 머신 / 인터랙션

이 두 프레임이 **직접 말해주는 것**:

1. **탭 행 + 검색 블록은 스크롤 밖 고정층**이다(A/B 픽셀 동일, 콘텐츠가 그 밑으로 잘림).
   현재 구현도 검색은 고정층이지만 **상단 3탭은 지금 다른 방식**이다(§7).
2. **`게시글` 제목과 정렬 드롭다운은 고정이 아니다** — B에서 함께 스크롤 아웃됐다.
   sticky section header 아님.
3. **정렬은 3개 인라인 텍스트 버튼이 아니라 드롭다운 칩 1개**다(`최신순 ⌄`).
   누르면 메뉴(시트 또는 앵커드 팝오버)가 열리고 `최신순 / 조회순 / 인기순` 중 하나를 고른다 —
   **열린 오버레이는 이 영역에 없다**. 닫힌 칩은 항상 현재 선택값을 라벨로 들고 있다.
4. **선택된 탭 표시** = 라벨 Bold + `label.normal` + 하단 2px 인디케이터(폭 62).
   비선택 = SemiBold + `label.neutral`.
5. **팔로우 버튼 2상태**가 한 화면에 같이 있다: `팔로잉`(solid `#FE7139`) / `팔로우`(tint).
   토글이며 낙관적 업데이트 대상.
6. **작성자 레일은 가로 스크롤**이다(3번째 카드가 프레임 밖으로 잘림). 첫 항목 inset 20, gap 8 →
   `contentContainerStyle` 에 좌우 20 을 주면 마지막 카드가 붙는다(v2 `RAIL_INSET` 규칙).
7. **작성자 레일은 피드 중간에 끼어든다** — 두 프레임 모두 글 **4개 뒤**에 한 번 나온다.
   두 번째 삽입 지점은 프레임에 안 잡혔다(레일 뒤로 A는 1행, B는 3행까지만 보임) → 주기 미정.
8. **행 구성은 가변**이다: 뱃지·태그칩·썸네일 각각 있을 수도 없을 수도 있다.
   목격된 4조합: (뱃지+칩+썸) / (칩+썸) / (썸) / (없음, 텍스트 전폭).
9. **FAB 은 고정**. 스크롤해도 같은 자리, 목록 위를 가린다.
10. **누름/비활성/로딩/빈 상태·스켈레톤은 이 영역에 없다.** 지금 구현의 스켈레톤·에러·빈 상태는
    시안에 없다는 이유로 지우면 안 된다(§7).
11. 행 사이 **간격 0** — 구분선으로만 나뉜다. 카드 간 gap(현재 10)은 사라진다.

## 7. 현재 구현과의 델타

대상: `src/features/recipe/components/FreePostTab.tsx`, `src/features/recipe/components/PostListItem.tsx`

### 이미 맞는 것
- 검색층이 **스크롤 밖 고정층**이라는 결정 (`styles.searchWrap`) ✔
- 검색이 입력이 아니라 `/community/search` **진입구**라는 결정 ✔
- 좌우 여백 **20** (`searchWrap`/`listItemWrap`/`chipRow`/`sortRow` 전부 20) ✔ — 시안과 동일
- 검색 필드 높이 44 ✔, 아이콘–텍스트 gap 8 ✔
- 피드가 `FlashList` + `ListHeaderComponent` 구조 ✔ (섹션 헤더/정렬을 헤더에 넣는 방식 유지 가능)
- 링 스피너 없음(`V2LoadingState`) ✔

### 바꿔야 하는 것

**A. 헤더**
1. 상단 `레시피 / 자유글 / 스토리` 3탭 + 우상단 프로필 아이콘이 **이 컴포넌트 밖(탭 스크린)** 에
   있어야 한다. 시안 사양은 `V2Tab size l`, 높이 51, 좌우 20 시작, 인디케이터 62×2.
2. 검색 필드: `borderRadius 14 → 12`, 배경 `surface.card`(흰색) → **`fill.normal`(`#70737C`@0.08)**,
   `paddingHorizontal 12 → 10`, 아이콘 `size 17 → 24`,
   placeholder `15 Regular / letterSpacing -0.3` → **17 Medium / letterSpacing 0**,
   색 `surface.placeholder` → `label.alternative`.
3. `searchWrap.paddingTop: 8` → 시안은 상하 14(→12 스냅).

**B. 목록 상단**
4. **`게시글` 섹션 제목 행(44)이 새로 필요**하다 — 현재 없음.
5. **카테고리 칩 레일(`전체/식단/수치/…`)이 시안 이 영역엔 없다.**
   지우기 전에 반드시 다른 섹션 시안을 확인할 것. 서버 `category` 파라미터를 먹는 실기능이다.
6. **정렬 UI 전면 교체**: 지금은 `최신순·조회순·인기순` 3개를 점(dot)과 함께 인라인 나열
   (`sortRow`/`sortDot`/`sortLabel`). 시안은 **드롭다운 칩 1개**(70×32, 흰 배경, 1px `line.neutral`,
   `최신순` 13 Medium + chevron 12). 누르면 3지선다 시트. `CommunitySortMode` 3값은 그대로 유지.

**C. 행(카드 → 리스트 행)**
7. `PostListItem` 을 **카드에서 행으로**: `borderRadius 16 / padding 16 / 카드 배경 / listGap 10` 제거,
   좌우 20 · 상하 16 · **하단 1px `fill.normal` 전폭 구분선** 으로 교체.

    **카테고리는 상단 다크 pill 뱃지**, **시간은 하단 메타행 오른쪽**으로 이동.
12. 하단 메타행 재구성: 지금은 `작성자명` (왼쪽) + `👁N ♥N 💬N` (오른쪽).

    **작성자명 없음**. 아이콘 14/13 → **16**, 색 `label.assistive`, 숫자 13 Regular `label.alternative`.

### 시안에 없지만 **반드시 보존**할 것 (지우지 말 것)

1. **케밥 메뉴(⋯) → `신고` / `차단`** (`PostListItem.handleMorePress`).
   시안 어디에도 없지만 스토어 심사·운영 필수 기능이다. 내 글이면 감추는 규칙(`isMine`)과
   탈퇴 작성자 규칙(`isWithdrawnAuthor`)도 그대로.
2. **차단 사용자 클라이언트 필터**(`visiblePosts`) — 차단 직후 한 박자를 메우는 장치.
3. **당겨서 새로고침**(`useRefreshable` + `spinnerOffset: searchLayerHeight`) 및
   `trimFeedCacheToFirstPage` 로 1페이지만 남기는 규칙.
4. **무한 스크롤**(`onEndReached` + `isPlaceholderData` 가드) 과 꼬리 로더 `V2LoadingState`(점 로더).
5. **스켈레톤 `CommunityFeedSkeleton`** — 시안에 로딩 상태가 없다는 이유로 삭제 금지.
   단, 새 레이아웃(행/썸네일 86)에 맞게 자리를 다시 잡아야 한다.
6. **에러 상태 `V2ErrorState`** 와 `feedFailed` 판정(placeholder 데이터를 정상처럼 보여주지 않는 규칙),
   `retryable` 일 때만 재시도 버튼.
7. **빈 상태**(`feed.emptyTitle` / `feed.emptyBody`).
8. **태그 필터 진입 상태**(`tagFilter` — `#태그` 칩 + 닫기, 태그 중에는 카테고리 미전송).
9. **`StoryRail`** — 시안에서 `스토리`가 최상위 탭으로 승격됐으므로 자유글 피드 안의 레일은
   빠지는 것이 자연스럽지만, **스토리 기능 자체를 지우면 안 된다**. 이동인지 삭제인지 확인 필요.
10. **인기글 레일(`PopularPostCard` + `useCommunityPopularPosts` + `/community-popular` 더보기)** —
    이 영역 시안에 없다. 삭제 전 다른 섹션 확인 필수.
11. **카테고리 필터 칩 레일** (위 B-5).
12. `useRevalidateOnReturn`, 햅틱(`hapticSelection`), `keyboardDismissMode="on-drag"`.
