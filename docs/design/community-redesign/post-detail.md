# post-detail — 자유글 게시물 상세 (헤더/본문/태그/메타/댓글/정렬/빈상태)

캔버스 구역: `x 100–3070, y 4810–5830`, 섹션 헤더 **"자유글- 인기글, 최신 게시글 / 게시물을 클릭했을때"** (검정 라벨 바, y≈4655–4735).
프레임 7개, 전부 `375 × 932`, 상단 y=4860.

**측정 방법 / 신뢰도**
- 좌표·크기·반경·색은 SVG 원본에서 파싱한 실측값(@1x px). 프레임 로컬 좌표 = SVG 좌표 − 프레임 원점.
- 글자는 아웃라인 패스라 폰트 크기를 잉크 bbox로 역산했다: 프로젝트의 실제 Pretendard(OTF, upm 2048, 한글 advance 0.8643em, 한글 잉크 높이 0.868/0.876/0.883/0.889em @Reg/Med/Semi/Bold, 숫자 cap 0.7168em)로 문자열별 잉크 폭·높이를 계산해 **폭 기준 추정치와 높이 기준 추정치가 일치하는 (크기, 굵기)** 조합을 골랐다. 아래 타이포 표의 값은 대부분 오차 ±0.05px 안에서 일치한다(예: "좋네요 참고하겠습니다" → Medium 13.00/13.00).
- letterSpacing 은 0으로 확인됐다(한글 문자열 폭이 Pretendard 0-tracking 계산과 정확히 일치). 유일한 예외는 날짜 문자열 → §3 각주.
- 줄간(lineHeight)은 같은 텍스트 노드의 줄별 잉크 top 간격으로 직접 측정(제목 19.0, 본문 20.0, 빈상태 18.96≈19).
- 텍스트 박스 top ↔ 잉크 top 변환에는 Pretendard hhea(asc 0.9521em / desc 0.2412em)를 썼다. RN 은 lineHeight 박스 안에서 폰트 라인박스를 세로 중앙정렬하므로 `잉크top = 박스top + (LH − 1.1934·fs)/2 + (0.9521 − 잉크top_em)·fs`.

## 5. 상태 머신 / 인터랙션

```
[게시글 상세]
  ├ 헤더 ‹  → 뒤로
  ├ 헤더 ⋯  → (디자인에 시트 없음) 게시글 액션 시트 = 현행 유지
  ├ 메타행 하트 탭 → 좋아요 토글:  회색(F2) ⇄ #FF4242(F3~F7)   ※ 수치는 목업상 그대로 541
  ├ 이미지 스트립 → 가로 스크롤 (탭 확대는 디자인에 없음 → 현행 유지)
  ├ 태그 칩 탭 → (디자인에 결과 화면 없음 → 현행 태그 검색 유지)
  ├ 정렬 트리거 `최신순 ▾` 탭 → [드롭다운 열림 F4]
  │     ├ `최신순` 선택 → 닫힘, 라벨 `최신순`
  │     └ `인기순` 선택 → 닫힘, 라벨 `인기순` (F5)   ※ 현재 선택 항목은 회색 pill 하이라이트
  ├ `마지막 댓글로` 탭 → 댓글 목록 마지막으로 스크롤(추정: 라벨이 곧 동작)
  ├ 댓글 행 ⋯ 탭 → (디자인에 시트 없음) 현행 액션시트(답글/수정/삭제/신고) 유지
  ├ 댓글 하트 탭 → 댓글 좋아요 토글 (디자인엔 눌린 상태 프레임 없음 → 게시글과 같은 #FF4242 규칙 적용 권장)
  ├ `답글쓰기` 탭 → **별도 화면 `답글쓰기`로 이동** (y=5892 행에 그 화면이 따로 있음)
  └ 댓글 0건 → [빈 상태 F7]
```
- **pressed/disabled 상태 프레임 없음**. 기존 v2 규칙(opacity 0.6 / fill.pressed)을 그대로 쓴다.
- **로딩/스켈레톤 프레임 없음**. v2 규칙대로 링 스피너 금지, 스켈레톤 우선 — 현행 `ArticleSkeleton` 유지.
- **키보드 업 레이아웃 없음**(이 구역엔 컴포저가 없다). 키보드 상태는 `답글쓰기` 화면 쪽 스펙에 있다.

| 좋아요/댓글 아이콘 | ⚠ v2 `heart` 는 **하트+플러스** 글리프(icon-heart.svg 에 십자 획 포함)라 디자인의 **민 하트**와 다르다. v2 `chat` 은 **원형 말풍선**인데 디자인은 **둥근 사각+좌하단 꼬리**. → 아이콘 2종 추가 제안: `heartFilled`(민 하트, 16 박스 잉크 12.3×11.05), `commentFilled`(둥근사각 말풍선) |
| 빈 상태 | ⚠ `V2EmptyState` 는 **title = title.small(20 Bold)** 로 강제 + 아이콘 `size 2xl(40)` 고정. 디자인은 **아이콘 71×69, 제목 없이 15 Medium 2줄 label.assistive**. 그대로 쓰면 다른 화면이 된다 → `V2EmptyState` 에 `tone="quiet"`(제목 15 Medium/assistive) + `iconSize` 옵션 추가하거나 로컬 구현. 아이콘은 v2에 없음(아웃라인 말풍선 3줄) → `commentEmpty` 일러스트 자산 추가 |
| 색 | 표 §4대로 전부 v2 시맨틱으로 커버됨(오프토큰은 `#D9D9D9` 하나, F1 전용) |
| letterSpacing | 디자인 0 = v2 규칙 ✔ (§3 날짜 각주만 예외) |

**§6.6 13 Medium / LH 20 (댓글 본문) 부재** — v2 타이포에 13 Medium 은 `label.xSmallWeak`(LH 16)·`subtext.mediumStrong`(LH 18) 뿐이고 **LH 20 조합이 없다**. 최소 추가 제안: `subtext.mediumStrongTall = {medium, 13, 20, 0}` 혹은 `body.xSmallStrong = {medium, 13, 20, 0}`. 대안으로 `body.xSmall`(13 Regular/20)을 쓰면 굵기만 한 단계 얇아진다(측정상 디자인은 Medium 이 정확히 일치).

**§6.9 F1 전용 요소** — `팔로우` 버튼(팔로우 도메인 자체가 앱/서버에 없음), 29px 아바타 댓글, 날짜-좌측 액션행은 정본(F2~F7)과 모순되므로 **구현 대상에서 제외**.

### 7.3 현행에만 있고 디자인에 없는 것 — **삭제 금지, 반드시 보존**
1. **하단 댓글 입력 바 전체**(`KeyboardStickyView` + `inputBar` + 전송 버튼 + `paddingBottom: 10+bottomInset`). 디자인 프레임에 최상위 댓글 작성 진입점이 **없다** — 지우면 댓글을 아예 못 단다. `답글쓰기` 화면이 답글만 담당하므로, 최상위 작성 경로는 유지한다.
2. **멘션 기능 일습**: `MentionSuggestions` 플로팅, 확정 멘션 칩(`mentionChips`), `applyMention/removeMention/retainedMentions`, `MentionText` 렌더.
3. **답글/수정 컨텍스트 배너**(`inputContext` — "답글 다는 중"/"수정 중" + 닫기 X)와 댓글 수정 플로우(`editingCommentId`, `updateComment`).
4. **댓글 더보기 액션시트**: 답글/수정/삭제(내 댓글) · 답글/신고(남의 댓글), `showActionSheet`.
5. **게시글 더보기(⋯) 액션**: 공유·삭제·신고 등 `handleMorePress` 흐름 — 디자인엔 시트가 안 그려졌을 뿐 ⋯ 버튼은 있다.
6. **공유·북마크**: 디자인 앱바에서 사라졌다. 기능 자체(`shareContent`, `togglePostBookmark`, 딥링크 `communityPostDeepLink`)는 **제거하지 말고** ⋯ 메뉴로 옮길 것.
7. **투표 카드 `PollCard`**(`post.vote`) — 디자인에 없지만 서버 모델(`CommunityPostVote`)과 작성 플로우가 살아 있다. 태그와 메타행 사이 위치 유지.
8. **이미지 전체보기 모달**(`previewImage` + `AppModal`) 및 이미지 탭 확대.
9. **당겨서 새로고침**(`useRefreshable`/`useRevalidateOnReturn`, `COMMUNITY_POST_REFRESH` 스코프).
10. **에러/삭제된 글/로딩 상태**: `resolveError`의 `retryable` 분기, `notFound`, `ArticleSkeleton`(스켈레톤 우선 규칙).
11. **탈퇴 사용자 처리**(`isWithdrawnAuthor` → `탈퇴한 사용자`, 프로필 진입 차단)와 **삭제된 댓글 플레이스홀더**(`comment.isDeleted`).
12. **차단 사용자 필터**(`useBlockedUsers` / `blockedNickNames`).
13. **작성자 프로필 진입**(`/community/author/{id}`) — 디자인은 작성자 행에 셰브론이 없지만 탭 동작은 남길 것(접근성 라벨 포함).
14. **이어 읽을 글**(`relatedPosts` + `rankRelatedPosts`) 섹션과 그 위의 8px 밴드.
15. **하트 스프링 애니메이션**(`HEART_SPRING`)·`hapticSelection`.
16. **소유자 판정은 서버 `isMine`**(`isMyContent`) — 닉네임 비교로 되돌리지 말 것.

### 7.4 구현 순서 제안
1. 토큰/타이포부터 교체(letterSpacing·fontWeight 제거) → 2. 앱바·본문 블록 리듬 → 3. 메타행(버튼 pill → 텍스트행 + 구분선) → 4. 정렬 바 + 드롭다운(신규) → 5. 댓글 행 재구성(아바타 제거·배지·날짜·행 보더·대댓글 틴트) → 6. 빈 상태 → 7. `답글쓰기` 화면 연결(해당 섹션 스펙과 합의).
