시안 `My Page Home*.svg`(혈압 4장) · `water/My Page Home*.svg`(수분 5장) · 체중 1장을 페이지로
옮기면서 훑은 경계들이다. 각 줄은 **무엇이 문제인가 → 지금 어떻게 되나 → 어디서 지키나**.

시안은 정상 흐름만 그린다. 아래는 그림에 없는 상태들이라 결정이 필요했다.

## 되돌리면 안 되는 것

1. **물·혈압·체중은 페이지다.** 시트로 되돌리면 이력 표와 입력이 스냅 높이를 다시 다툰다.
2. **혈압은 격자다.** `(user, date)` 유니크로 되돌리면 저녁 측정이 아침 값을 지운다.
3. **끼니당 한 행 유니크는 폐기됐다.** 되살리면 두 번째 점심이 23505 로 터진다.
4. **미확정은 0 이 아니다.** 합계를 0 으로 그리면 "안 먹었다" 로 읽힌다.
5. **물색은 시안보다 한 단 짙다.** 시안 값 위의 흰 숫자는 2.55:1 이라 읽히지 않는다.
