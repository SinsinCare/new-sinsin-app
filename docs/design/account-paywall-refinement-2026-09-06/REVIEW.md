# 내정보·프리미엄 페이월 재정리

## 이번 개선의 기준

지난 개편은 건강 정보를 세 항목으로 줄이고 플랜을 일반 메뉴로 처리해 화면의 성격과 정보 위계가 약해졌다. 이번에는 기본 글자 크기를 키우지 않고 실제 건강 정보, 관련 행동, 멤버십 제안을 구분했다.

Mobbin에서 아래 화면을 실제 이미지로 비교했다.

- [Fitbit 프로필](https://mobbin.com/screens/136405f3-5e19-474e-b504-5b089111af63): 프로필과 멤버십을 별도 역할로 묶는 방식.
- [NAVER 마이](https://mobbin.com/screens/a674134d-664d-4d0c-9f82-1942b50b40f8): 작은 멤버십 진입점과 짧은 기능 바로가기.
- [Toss](https://mobbin.com/screens/44c0d237-000a-4dac-8b60-c9b19b80366a): 중립 배경 위에 역할별 카드, 카드 내부의 촘촘한 정렬.
- [MyFitnessPal 구독 흐름](https://mobbin.com/flows/3e8f40b1-8e02-4615-bfec-53f6ca5cb0c3): 요금 선택과 구매 CTA를 분리하고 선택한 가격을 명확하게 안내.
- [Headspace 페이월](https://mobbin.com/screens/a9bf58c3-250a-4565-9808-c4722933ea54): 캐릭터의 친근함과 설명/가격/행동의 구분. 무료 체험·할인 문구 자체는 복사하지 않았다.

## 결과

### 내정보

- 프로필 수정은 상단, 설정 진입은 헤더에 유지.
- 건강 카드에 병기·투석 여부·키/체중·진단 시기·동반 질환/진단 원인을 표시. 미입력 값은 추정하지 않는다. 병기를 진행률처럼 표현하지 않는다.
- 의료진 연결, 건강검진, 기록 내보내기는 건강 카드 하단의 세 바로가기. 확대 글자에서는 줄바꿈하면서 아이콘의 시작 위치 유지.
- 현재 플랜과 캐릭터가 있는 멤버십 카드로 프리미엄 진입을 안내. 무료/유료/확인 중을 구분하며 유료 사용자는 기존 구독 관리로 연결한다.
- 다크 모드는 어두운 페이지 위로 카드를 구분하고 본문 색상과 상태표시줄 대비를 유지한다.

### 페이월

- 좌우 24 pt 기준선, 20 pt 제목, 15 pt 혜택 제목, 13 pt 설명. 강조색은 브랜드 라벨·선택 테두리·CTA에 집중.
- 연간/월간 라디오 옵션에 스토어가 제공한 전체 가격 표시. 연간의 월 환산 금액은 보조 정보로 두고 하단에 실제 청구 금액과 결제 주기를 반복 안내.
- 동일 통화의 유효한 월간/연간 가격일 때만 계산한 할인율을 표시. 체험·할인·한국 원화 가격을 만들어 넣지 않는다.
- 혜택은 상품 로딩과 무관하게 유지. 실패/다시 시도 상태와 구매 복원 접근 제공. 로딩 중 이전 상품이나 가격으로 구매할 수 없도록 처리.
- 본문만 스크롤하고 결제/자동 갱신 안내/복원 영역은 하단에 유지. 확대 글자에서 ScrollView의 intrinsic height가 footer를 밀어내던 문제는 시트 detent와 drag handle에 맞춘 명시적 viewport로 해결.
- 구매/복원의 공통 잠금을 상태 업데이트 전 동기적으로 획득. 구매 완료 뒤 기존 서버 동기화 계약 유지. 닫았다 다시 연 페이월을 이전 비동기 응답이 닫지 않는다.
- 취소는 오류 안내를 띄우지 않는다. 상품 로딩 오류, 구매 오류, 복원 오류를 구분한다.

## 검증

- iPhone 17 Pro / iOS 26.5, 기존 로컬 TEST backend 8100 + Metro 8085.
- 현재 TEST offering의 연간/월간 가격으로 실제 화면 로딩, 기본 연간 선택, 월간 선택과 하단 가격 반영, 닫기 및 재진입 확인.
- 건강 정보 보기·수정 → 변경 없이 뒤로가기, 내정보 → 설정 → 내정보 복귀 확인.
- 라이트/다크 화면 확인. 다크 상태표시줄은 모달 안의 StatusBar와 닫기 lifecycle에서 처리.
- iOS `accessibility-medium`에서 글자 확대 후 앱 재실행하여 건강 카드 줄바꿈 및 페이월 본문 스크롤, 월간 선택, 고정 결제/복원 영역 확인. `simctl`로 실행 중 글자 크기를 바꾸면 기존 native text의 측정 캐시가 한동안 남아 재실행 후 검수했다. 가장 큰 접근성 단계 전체를 검증한 것은 아니다.
- 최종 기본 글자 크기 `large`, 한국어, 라이트 모드로 복구.
- Jest 5 suites / 49 tests 통과. 가격/복원/402 연결 기존 검증과 상품 재로딩, stale 응답, 중복 구매·복원, 서버 동기화, SDK 오류 시 잠금 해제 검증 포함.
- `tsc --noEmit`, 변경 파일 ESLint 통과. 문구 감사 12개 기존 후보는 다른 영역이며 이번 변경 문구 후보 없음.

실제 결제나 구매 복원은 실행하지 않았다. 결제 성공/실패/복원/상품 불러오기 실패의 비동기 동작은 단위 테스트 증거이며, App Store 실청구/실제 유료 계정 화면/Android 검증은 아니다. 기존 공유 작업 내용은 보존했고 배포하지 않았다.
