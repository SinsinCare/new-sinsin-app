# 페이월 메시지와 시각 디테일

## 적용

- `하루 …꼴`을 제거하고 `하루 {가격}` / `식사 고민은 가볍게`로 구성했다. 마지막 피드백에 따라 가격 뒤 쉼표도 제거했다.
- 상단은 하루 비용과 혜택을 전달한다. 기간 선택 카드에서는 실제 결제액을 우선하고 하루 평균 비용은 보조 정보로 표시한다. 연간 365일·월간 30일 환산 기준을 유지한다.
- 결제 CTA는 선택한 상품에 따라 `연간 구독하기` / `월간 구독하기`로 바뀐다. 내정보·구독 관리에서 페이월을 여는 버튼은 `프리미엄 혜택 보기`로 구분한다.
- 기능 설명은 영양소 확인, 건강 기록을 활용한 AI 상담, 지난 기록의 변화라는 사용 이점으로 다듬었다. 상품·가격·구독 정책·법률 안내는 바꾸지 않았다.
- 내정보 카드의 가격과 혜택 제목을 2pt 간격으로 묶고, 보조 정보는 8pt 간격으로 분리했다. 요금 카드 테두리는 1pt, 모서리는 14pt로 정돈하고 숫자는 오른쪽 정렬과 tabular figures를 적용했다. 할인 배지는 세로 패딩을 1pt로 줄였다.
- CTA는 큰 글씨나 긴 번역에서 줄바꿈할 수 있도록 기존 버튼의 multiline 옵션을 사용한다.

## 검증

- 기존 결제 관련 Jest 6개 스위트, 55개 테스트 통과. 마지막 스타일·문장부호 수정 뒤 TypeScript 및 수정한 TSX 파일의 ESLint도 통과했다.
- 한국어 문구 감사 실행. 교정 후보 12개는 이번 수정 파일 밖에 있었다.
- 로컬 TEST iPhone 17 Pro / iOS 26.5 Simulator에서 최종 라이트 내정보 카드와 연간 페이월, 쉼표 제거, 얇은 카드 테두리, 결제액 및 연간 CTA 표시를 확인했다.
- 월간 버튼 검수 시 CUA가 사용자의 Simulator 조작을 감지해 액션을 중단했다. 사용자 조작과 충돌하지 않도록 추가 화면 이동·폰트 및 모드 변경을 멈췄다. **이번 수정본의 월간 전환, 다크 모드, 접근성 글씨 크기 재검증은 완료하지 않았다.** 앞선 가격 개선 턴의 검증과 구분한다.
- 실제 구매·복원은 실행하지 않았다. 마지막 읽기에서 한국어·라이트 내정보가 표시되어 있었다.
