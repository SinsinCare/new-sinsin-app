# 3. 위험등급 분류

## 3.1 문서 이력

| 버전 | 일자 | 작성/수정 | 비고 |
|------|------|------------|------|
| 0.1  | (작성일) | (담당자명) | 초안 |

## 3.2 분류 근거 (의료기기법·시행규칙)

- 본 제품은 **인체에 직접 작용하지 않는** 소프트웨어이며, **진단·치료·예방을 직접 수행하지 않고** 식이·건강 관리 **보조 정보**를 제공합니다.
- **침습적 사용 없음**, **생명 유지 직접 연동 없음**, **치료·진단 결정을 대체하지 않음**을 전제로 합니다.

### 3.2.1 적용 가능 분류

- 식품의약품안전처 「의료기기 분류기준」 및 소프트웨어 의료기기 관련 고시에 따라:
  - **2등급(준수)** 또는 **1등급(일반)** 소프트웨어 의료기기로 분류될 수 있는 범위에 해당할 수 있습니다.
  - 최종 등급은 식약처 분류 심사 및 상담 결과에 따릅니다.

### 3.2.2 분류 시 고려 사항

| 구분 | 내용 |
|------|------|
| 사용 목적 | CKD 환자의 식이·건강 관리 보조(참고용 정보 제공) |
| 위험 요인 | 잘못된 정보 제공 시 식이 오판 가능성 → 사용 설명서·화면 내 주의 문구로 “참고용”, “의사 상담 권장” 명시 |
| 사용자 | 일반 환자(비전문가) 자가 사용 |
| 환경 | 비병원, 일상 환경 |

## 3.3 위험 분석 개요 (ISO 14971 관점)

| 위험 | 완화 조치 |
|------|------------|
| AI 분석 결과를 치료·처방으로 오인 | 앱 내 “참고용”, “의사·영양사 상담 권장” 문구, 사용설명서 명시 |
| 영양소 제한치·CKD 단계 입력 오류 | 사용자 입력 검증, 단위·범위 안내, 프로필 수정 가능 |
| 개인정보·건강정보 유출 | 접근 제어, 암호화, 개인정보처리방침·약관 정비 |
| 소프트웨어 오동작으로 정보 미제공/오제공 | 요구사항·검증·배포 전 테스트, 오류 메시지 및 복구 안내 |

## 3.4 분류 결론(안)

- **제안 위험등급**: [ 1등급(일반) / 2등급(준수) 중 심사 후 확정 ]
- **근거 요약**: 비침습·비생명유지·보조용 소프트웨어이며, 진단·치료 대체가 아니므로 상대적으로 낮은 위험등급에 해당할 수 있음. 최종은 식약처 분류 상담·심사에 따름.
