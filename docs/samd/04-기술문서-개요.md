## 4.2 소프트웨어 생명주기

- **개발**: 요구사항 정의 → 설계 → 구현 → 단위/통합/시스템 테스트
- **배포**: 앱 스토어 제출, 버전 관리, 릴리스 노트
- **운영**: 모니터링, 장애 대응, 보안·개인정보 대응
- **유지보수**: 버그 수정, 소규모 기능 개선, 보안 패치

참조: IEC 62304에 따른 소프트웨어 생명주기 활동을 적용·정리할 수 있습니다. (신청 시 소프트웨어 생명주기 문서에서 상세 기술)

## 4.3 시스템 구성 개요

| 구성요소 | 기술 요약 |
|----------|------------|
| 클라이언트 앱 | React Native(Expo), iOS/Android 공통 빌드, Tamagui UI |
| 인증·DB | Firebase Authentication, Cloud Firestore |
| AI 기능 | 백엔드 API (/analyze-food, /chat) 연동 |
| 데이터 | user_profiles, health_records, food_records, conversations, messages, daily_health_logs |

## 4.4 주요 요구사항 개요

- **기능**: 사용자 인증, CKD 단계·투석 여부 프로필, 건강 기록·일일 로그, 식품 기록 및 AI 분석 결과 표시, AI 상담 채팅
- **품질**: 입력 검증, 오류 처리, 오프라인/네트워크 오류 시 사용자 안내
- **보안·개인정보**: 인증된 접근, 전송·저장 시 암호화, 개인정보처리방침 준수

## 4.5 검증·테스트 개요

- 단위 테스트: 핵심 로직·서비스 레이어
- 통합 테스트: API·Firebase 연동
- 시스템/수용 테스트: 주요 사용 시나리오(회원가입, 프로필, 식품 분석, 상담) 검증
- 배포 전 회귀 테스트 및 버전별 릴리스 체크리스트

## 4.6 제출 시 기술문서 목록(안)

- 소프트웨어 요구사항 명세서
- 소프트웨어 설계 개요(아키텍처·주요 흐름)
- 소프트웨어 검증·테스트 요약
- 위험관리 요약(03-위험등급-분류.md와 연계)
- 소프트웨어 버전 정책 및 변경 이력
