# 지도 지역 전환과 빈 결과 복구

2026-09-08 후속 점검. 전체 페이지를 직접 사용하는 장기 목표의 지도 작업 일부이며, 전체 기능 검증 완료를 뜻하지 않는다.

## 재현과 수정

- 새 지역 필터가 이전 bbox와 함께 조회될 수 있었다. 지역 이동을 시작하면 이전 질의 조건을 유지하고, 도착한 viewport의 확정에 성공한 뒤 새 필터를 공개한다. 지도와 목록은 전환 중 새 요청을 시작하지 않는다. 기존 결과는 유지하고 로딩 상태를 표시한다.
- 첫 구현은 도착 좌표를 고정된 0.00001도 오차로 비교해 실제 Kakao panTo의 픽셀 보정을 거부했다. Simulator에서 도착 후에도 로딩이 남았고, 위도 차이 약 0.00001269도를 확인했다. 실측 viewport 크기와 bounds에서 구한 2픽셀 범위로 수정했다. 임시 차이 로그는 제거했다. 이는 시간 초과로 임의 해제하는 방식이 아니다.
- 같은 중심의 이동은 Kakao idle이 발생하지 않을 수 있다. 실제 화면 좌표가 2픽셀 이내이고 배율이 같으면 중심을 맞추고 viewport 완료 이벤트를 보낸다. 배율 변경은 기존 명령을 수행한다.
- 서초 필터 적용 후 최근 강남 검색을 누르면 강남 카메라에서 서초 식당만 115곳 표시되는 충돌을 재현했다. 지역 검색은 기존 지역 범위를 해제한다. 다른 확정 조건은 유지하며, 닫았던 필터 초안이 되살아나지 않는다.
- 제주 빈 결과의 복구 버튼이 중간 스냅에서 탭 바에 가려졌다. 지도 시트의 빈 상태에서만 장식 아이콘을 빼고 여백을 줄였다. 제목·본문 크기와 표준 버튼은 유지했다. 전체 화면의 빈 상태는 기존 구성을 사용한다.

## 실제 앱 확인

기존 로컬 API 8100, Metro 8085, 실제 Kakao WebView를 사용했다. iPhone 17 Pro / iOS 26.5, 한국어 라이트 모드에서 CUA 접근성 버튼과 화면 캡처로 확인했다. 데이터 초기화·시드·운영 변경은 하지 않았다.

1. 수동 서초 적용: 로딩 종료 후 4곳과 서초 목록 확인.
2. 서초·한식 적용 → 최근 강남 선택: 지역 조건 해제, 한식 유지, 161곳과 강남 한식 목록 확인.
3. 같은 강남을 다시 선택: 이동이 거의 없어도 로딩이 종료되고 161곳 유지.
4. 제주 전체·한식 적용: 0곳 표시. 필터 초기화 후 조건 없음 상태로 전환. 복구 버튼이 화면에 온전히 보이는 것을 캡처로 확인.
5. 지도 넓혀서 다시 찾기: 제주 지도 배율이 변경되고 조회 완료. 해당 지역에 등록된 결과가 없다는 상태는 유지.
6. 최근 강남 선택: 334곳 정상 목록으로 복구.
7. AI 검색에 서초 한식 식당 입력 → 서초·한식 해석 → 조건 적용: 지역 1·한식 선택·서초 4곳으로 완료.

목록 수치는 당시 로컬 데이터와 viewport의 결과이며 식당 정보의 사실성이나 운영 데이터 품질 검증을 뜻하지 않는다.

## 자동 검사와 범위

- TRANSITION-GATES:T1은 지역 전환 훅, 실제 생성 지도 명령, 지도 HTML, viewport 정책, 필터 상태, 목적지, 최근 검색 관련 6개 스위트를 실행한다. 오래된 idle, 빠른 재선택, 수동 이동으로 소유권 변경, viewport 거절 시 보류, WebView 재시도 목적지 유지, 픽셀 보정, 동일 위치 완료를 검증한다.
- TRANSITION-GATES:T2는 전체 TypeScript와 이번 경로 ESLint·Prettier를 실행한다. 변경 경로의 git diff --check도 통과했다.
- 중간 전환에서 잘못된 조건이 공개되지 않는 것은 훅 회귀와 화면 연결 코드 검토로 확인했다. 모든 네트워크 요청을 프레임과 함께 계측한 검증은 아니다.
- 빠른 연속 선택·수동 제스처 중단·WebView 복구는 합성 회귀 범위다. 실제 네트워크 단절과 프로세스 회수는 이번에 재현하지 않았다.
- Android, 실기기, 작은 화면, 다크 모드, 큰 글씨는 이번 확인 범위 밖이다. 지도 마커/카드/사진/상세의 모든 제스처가 검증된 것도 아니다.
- 이전 REVIEW.md의 전역 탭 라우트 테스트 1건 실패는 이번에 변경하거나 재실행하지 않았다. 전체 저장소 회귀 통과를 주장하지 않는다.
